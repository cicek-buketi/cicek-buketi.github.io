# Gece Buketi — Kişiye Özel Çiçek Buketi

Sevdiklerinize yıldızlı gece gökyüzü altında açan, ışıldayan kişiye özel çiçek buketi ve gizli mektup gönderebileceğiniz tamamen statik web uygulaması.

## Özellikler

- **Herkes İçin Özel Link Üretici:** Veritabanı veya sunucu gerekmeden, isim, çiçek türü, renk/ışık tonu ve mektup notunu kodlu bir URL içine gömer.
- **12 Farklı Çiçek Modeli:** Gece Çiçeği *(orijinal ışıldayan form)*, Papatya, Gül, Lale, Sakura, Orkide, Zambak, Lavanta, Nilüfer (Lotus), Ortanca, Karanfil ve Karışık Buket.
- **12 Renk & Işık Tonu:** Gece Turkuazı, Aşk Kırmızısı, Pembe Rüya, Mor Lavanta, Altın Işıltı, Saf Beyaz, Safir Mavi, Mercan Günbatımı, Zümrüt Yeşili, Neon Fuşya, Kadife Bordo ve Buz Mavisi.
- **Çiçeği Kapatmayan Zarf & Mektup:** Buketin altında beliren kalp mühürlü zarfa tıklandığında, masaüstünde yanda, mobilde ise buket üstte görünmeye devam edecek şekilde altta açılır.
- **Etkileşimli Yıldızlı Gece:** Tıklama/dokunma ile gökyüzünde yumuşak yıldız parıltıları oluşur.
- **%100 GitHub Pages Uyumlu:** Saf `HTML + CSS + JS` ile çalışır.

## Dosya Yapısı

- `index.html` — Buket oluşturucu stüdyo ve hediye ekranı iskeleti
- `style.css` — 6 ışık teması, çiçek büyüme/açılma animasyonları ve mobil/masaüstü düzenleri
- `app.js` — 5 çiçek türü SVG üreticisi, yıldızlı gece tuvali, zarf/mektup kontrolü ve URL kodlayıcı
